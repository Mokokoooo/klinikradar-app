# KlinikRadar – App-Downloads

Hier liegen die fertigen Apps von KlinikRadar zum Herunterladen. Der Datensatz ist in der App enthalten, ein Konto oder Token ist nicht nötig.

## Android

1. Unter [Releases](../../releases/latest) die Datei `KlinikRadar-<Version>.apk` herunterladen.
2. Öffnen und die Installation aus dieser Quelle erlauben, wenn Android danach fragt.
3. Neue Versionen erscheinen ebenfalls unter Releases und können einfach darüber installiert werden.

## iPhone

Die iPhone-App wird über [SideStore](https://docs.sidestore.io) installiert, ohne App Store.

1. SideStore einmalig einrichten ([Anleitung](https://docs.sidestore.io/docs/installation/prerequisites)).
2. Die Installationsseite öffnen und „Quelle in SideStore hinzufügen“ antippen: https://mokokoooo.github.io/klinikradar-app/
3. KlinikRadar unter „Browse“ installieren. Updates erscheinen dort automatisch.

Die Signatur einer kostenlosen Apple-ID läuft nach 7 Tagen ab. SideStore erneuert sie im Hintergrund, wenn die App regelmäßig geöffnet wird.
